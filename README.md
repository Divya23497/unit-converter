# Unit Converter App (React + Node.js + Express + MongoDB)

A full-stack Unit Converter application where measurement types, units, and their conversion values are completely dynamic and stored in a database.

This app allows users to:
- Add measurement types (Length, Area, etc.)
- Add units for each measurement type (Meter, Kilometer, etc.)
- Define conversion values (e.g., 1 km = 1000 m)
- Convert values between any units dynamically

---

## Tech Stack

### **Frontend**
- React + TypeScript
- Axios
- Bootstrap

### **Backend**
- Node.js
- Express.js
- MongoDB + Mongoose
